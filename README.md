# UCAB – MERN Stack Cab Booking System

## Project Overview
UCAB is a full-stack cab booking web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The application allows users to register, log in, book cabs, and view booking history. Drivers can manage assigned rides, and administrators can manage users, cabs, and bookings.

## Features
- User Registration & Login
- JWT Authentication
- Cab Booking
- Booking History
- Driver Dashboard
- Admin Dashboard
- Manage Users
- Manage Cabs
- Dashboard Statistics
- MongoDB Database

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Bootstrap
- Axios
